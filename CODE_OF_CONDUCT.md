# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and receive feedback constructively. Harassment, discrimination, and personal attacks are not welcome.

Report concerns privately to the project maintainer at the address listed in [SECURITY.md](SECURITY.md). Reports are handled confidentially.

Full text of the standards, responsibilities, and enforcement process: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
